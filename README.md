
# 🎓 Can I Graduate?

> ***'나 졸업할 수 있을까?'***
>
> 대학생을 위한 졸업 학점 계산 및 졸업 요건 관리 서비스

---

## 🌱 1. 프로젝트 개요

**Can I Graduate?** 는 대학생이 자신의 졸업 요건 충족 여부를 종합적으로 확인하고 관리할 수 있도록 돕는 웹 서비스입니다.

총 이수 학점뿐 아니라 전공 및 교양별 이수 기준, 필수 과목, 외국어 성적 등 학교와 학과에서 요구하는 다양한 졸업 요건을 관리할 수 있도록 지원합니다.

## 🎯 2. 프로젝트 목표

- 졸업에 필요한 다양한 요건을 한눈에 확인합니다.
- 영역별 취득 학점과 부족한 학점을 자동으로 계산합니다.
- 학점 외 졸업 요건의 충족 여부와 진행 상태를 관리합니다.
- 미충족 요건을 파악하여 졸업 준비 계획을 세울 수 있도록 지원합니다.

## ✨ 4. 주요 기능

### 📊 대시보드

- 전체 졸업 요건 및 충족 현황 요약
- 총 취득 학점과 졸업 기준 학점 비교
- 전공 및 교양별 이수 현황 표시
- 학점 외 졸업 요건의 진행 상태 표시

### 📝 학점 관리

- 수강 과목 및 취득 학점 입력
- 전공 필수, 전공 선택, 교양 등 영역별 구분
- 영역별 이수 학점 자동 계산
- 졸업 기준 대비 부족한 학점 확인

### 🎓 졸업 요건 관리

- 총 이수 학점 및 영역별 학점 기준 관리
- 전공 필수 과목 이수 여부 확인
- 기타 학교 및 학과별 졸업 요건 등록
- 각 요건의 충족, 미충족, 진행 중 상태 표시

### 📅 졸업 준비 계획

- 미충족 졸업 요건 확인
- 학기별 수강 예정 과목 등록
- 졸업시험, 논문 등 비학점 요건의 일정 관리
- 요건별 완료 상태 및 진행 상황 업데이트

## 📌 7. 개발 범위

### MVP — 1차 구현

- [ ] 회원가입 및 로그인
- [ ] 학점 및 졸업 요건 데이터 저장
- [ ] 졸업 기준 설정
- [ ] 수강 과목 및 학점 입력
- [ ] 졸업 학점 충족 여부 확인
- [ ] 졸업 요건별 충족 상태 표시
- [ ] 미충족 요건 대시보드 표시

### 추후 확장 기능

- [ ] 시간표 파싱을 통한 수강 내역 등록 (에타 시간표 기준)
